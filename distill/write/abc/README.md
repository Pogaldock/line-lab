Letter shapes for the writing experiments, derived from Marck Script by Denis Masharov (SIL Open Font License 1.1).
`<letter>_0.json` is the font form, `<letter>_1.json` a loopier form (re-traced stems become loops). Font units:
origin on the baseline at the pen start, 1 = font size. Made with font2cap.py (RAW=1, LOOPF=0.04 / 0.10).
